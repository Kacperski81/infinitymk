# 3D Transform Functions: Complex Combined Transforms

## Principle
`matrix3d()` is a 4×4 transformation matrix for precise control over all 3D transforms at once. It can express any combination of translation, rotation, scale, and skew in a single function.

## Application
```css
/* Simple rotation expressed as matrix3d */
.element {
  transform: rotateY(45deg);
}

/* Equivalent matrix3d form */
.element {
  transform: matrix3d(0.707, 0, 0.707, 0, 0, 1, 0, 0, -0.707, 0, 0.707, 0, 0, 0, 0, 1);
}

/* More practical: use composed transforms instead */
.element {
  transform: rotateY(45deg) translateZ(100px) scaleZ(1.2);
}
```

## Key Guidelines
- **16 values** in column-major order representing 4×4 matrix
- **Rarely use directly** unless generated by JavaScript or libraries
- **Prefer composed functions**: `rotateY() translateZ() scaleZ()` are clearer
- **Useful for**: Animation library output, computed transforms, precise positioning
- **Performance**: No advantage over composed functions

## Matrix Structure
```
matrix3d(m11, m21, m31, m41,
         m12, m22, m32, m42,
         m13, m23, m33, m43,
         m14, m24, m34, m44)
```

## Why It Matters
While `matrix3d()` is mathematically complete, it's rarely written by hand. Compose simpler functions for readability. Use `matrix3d()` when:
- Animation libraries generate it
- Computing transforms in JavaScript
- Implementing advanced animation sequences
- Migrating from other 3D frameworks

## Common Scenarios
```css
/* Skewing isn't available in other 3D functions */
.element {
  /* Would use matrix3d for skew, but skew is complex */
}

/* JavaScript-computed transform */
.element {
  /* Computed and applied as matrix3d by library */
}
```

## When to Use vs Composed Functions
```css
/* ✅ Preferred: composed functions (readable) */
.element {
  transform: perspective(1000px) rotateX(10deg) rotateY(20deg) translateZ(100px);
}

/* ⚠️ Rarely written manually: matrix3d (hard to understand) */
.element {
  transform: matrix3d(0.952, 0, 0.306, 0, -0.060, 0.985, 0.156, 0, -0.305, -0.172, 0.936, 0, 0, 0, 100, 1);
}
```

## Browser Inspection
- DevTools often display computed matrix3d for composed transforms
- Copy matrix3d from computed styles only if needed for performance testing
- Safer to recompose with individual functions
